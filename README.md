# «Застолье» — семейный ресторан (дорой сайт)

Созданный сайт ресторана (frontend) + инвентарное ТЗ: [TZ.md](TZ.md).

## Как открыть
```
Откройте файл index.html в браузере,
например: file:///home/user/restaurant-site/index.html
```
Или запустите локальный сервер:
```
python3 -m http.server 8000   # в папке restaurant-site
# http://localhost:8000
```

## Инвентарь сайта (из ТЗ)
- Название: «Застолье», город: Екатеринбург, ул. Волжская д. 11
- Меню: 19 блюд (Завтраки / Салаты / Горячее / Десерты / Барная карта)
- Интерактивная корзина доставки (±1, итого, калькулятор стоимости)
- Бронирование (дата, время, гости, комментарий, чекбокс)
- Фотогалерея, модальные окна, фильтры меню, хиты меню (карусель)
